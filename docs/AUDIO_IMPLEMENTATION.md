# 에테르 아크 — 음향 구현 0.10

기준일: 2026-09-05. 문서상 다음 미완료 항목인 음악·효과음의 첫 플레이 가능한 구현입니다. 최종 상용 OST가 아닌 오리지널 합성 프로토타입입니다. 외부 게임 음악, 녹음 샘플, 음성, 상용 라이브러리를 사용하지 않았습니다.

## 적용 내용

| 상황 | 음원 | 구성 |
|---|---|---|
| 메뉴·준비·항로 | `Music/voyage.wav` | 76 BPM, 8마디, 잔잔한 패드·벨·저음 |
| 항구 | `Music/port.wav` | 90 BPM, 8마디, 밝은 아르페지오·가벼운 타악 |
| 사건 | `Music/encounter.wav` | 68 BPM, 8마디, 절제된 저음과 공명 |
| 일반 전투 | `Music/combat.wav` | 118 BPM, 8마디, 반복 저음·킥·스네어 |
| 천공문 전투 | `Music/finale.wav` | 132 BPM, 8마디, 촘촘한 펄스·타악 |

루트는 `Assets/_Project/Resources/Audio/`입니다. `Effects/`에는 확인·거부·포격·피격·빗나감·출격·복귀·공명·경고·위급·정지·재개·승리·패배의 14개 클립이 있습니다. 일반 전투 승리/지역 돌파에도 승리 효과음이 재생되고, 최종 승패 화면에서는 BGM이 사라지며 결과 효과음만 남습니다.

모든 화면의 **음향 / F10**에서 음악·효과음 볼륨을 각각 10% 단위로 조절하고, 전체 음소거와 효과음 미리 듣기를 사용할 수 있습니다. 기본 음악 50%, 효과음 70%. **Esc / F10**으로 닫습니다. 실행 중 전투를 열어 두면 위험하므로 설정 중에는 전투가 멈추고, 닫으면 열기 직전의 일시정지 상태로 복원됩니다. 음소거와 효과음 0%는 경고음도 끄지만 기존 시각 경고·자동 정지는 그대로 유지됩니다.

## 구조와 안전장치

- `AudioCatalog`: 게임 단계 → BGM, 실제 시뮬레이션 로그 → 효과음 매핑. 승패는 무음 BGM 상태이며 이전 저장 로그는 재생하지 않음.
- `GameAudio`: UI 트리 바깥에 음악 2채널 + 일반 효과 4채널 + 경고/결과 전용 1채널. 최대 7개 `AudioSource`만 사용. 명령·화면 갱신 횟수에 따라 오브젝트가 늘어나지 않음.
- 음악 변경 시 1.6초 크로스페이드. 일시정지/음향 설정에서 음악이 정상 레벨의 40%로 부드럽게 감소. 동일 상태나 언어/UI 갱신은 음악을 재시작하지 않음. 재생 속도는 전투 배속과 독립적.
- `GameSimulation.LogAdded`와 `CombatAlertRaised`는 저장되지 않는 표시 계층 알림. RNG를 사용하지 않으며, 과거 로그를 순회하지 않음. 다른 런으로 바꾸면 이전 구독과 남은 효과음을 해제.
- 같은 일반 효과는 90ms, 주요 효과는 1.2초 간격 제한. 경고는 2초 제한하되 위급 단계로 상승하면 즉시 통과. 정보성 편대 알림은 경고음을 내지 않음.
- 효과음은 PCM·메모리 전개, 음악은 Vorbis·압축 메모리 유지. 샘플 누락은 해당 소리를 건너뛰며 경고를 남김. 모든 소리는 2D이며 씬에 리스너가 없을 때만 하나 생성.
- 프로필만 스키마 v2. v1은 음악 50%·효과음 70%·음소거 해제로 이전하고 기존 함장·접근성·해금은 보존. 런은 v1 유지. 잘못된 수치와 누락된 음향 설정을 정규화하고 명시적인 0%는 보존.

## 음원 생성과 검증

`tools/gen_audio.py`는 Python 표준 라이브러리만 사용하는 작곡·합성 소스입니다. D 중심의 자체 작성 8마디 화성과 모티프를 신스 패드·벨·저음·필터 노이즈로 합성합니다. 22,050 Hz / 16-bit / 스테레오 WAV 19개, 합계 약 10MB. 음악의 릴리스 꼬리는 시작 부분으로 감아 루프를 만들고, 효과음에는 끝단 페이드를 적용했습니다.

```sh
python3 tools/gen_audio.py             # 생성 (WAV를 갱신)
python3 tools/gen_audio.py --validate  # 포맷·RMS·피크·길이·루프 이음새·끝단 클릭 검사
python3 tools/gen_audio.py --check     # 재생성 결과와 커밋 음원의 SHA-256 일치 확인
python3 tools/validate_project.py
bash tools/compile_all_csharp.sh
```

Unity EditMode는 모든 리소스의 로딩/임포트 정책, 상태별 음악 선택, 프로필 v1/v2 실제 JSON 픽스처 이전·왕복, 알림 구독 유무에 따른 결정론적 상태 동일성을 검사합니다. PlayMode는 반복 갱신 중 음악 전환 횟수, 일시정지 감쇠/음소거, 발사·출격 이벤트, 이전 런 구독 해제, 경고 제한/위급 상승, 실제 설정 버튼의 저장과 일시정지 복원을 검사합니다.

이번 검증: EditMode 136개, PlayMode 10개 통과. WAV 19개 재생성 일치·신호 검사와 런타임 컴파일 스모크 통과. macOS 개발 빌드 성공 및 한국어·영어/고대비 음향 패널과 전투 상단 버튼 배치를 화면으로 확인했습니다. 실제 장시간 청취 평가 및 Windows 빌드는 수행하지 않았습니다.
