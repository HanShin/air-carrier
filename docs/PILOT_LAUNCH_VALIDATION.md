# 조종사 출격 검증과 UI 안내

기준일: 2026-09-05. 편대 정책 감사에서 발견한 조종사 검증 누락을 게임 명령과 전투 UI에 반영했습니다. 게임 수치·콘텐츠·세이브 스키마는 변경하지 않았습니다.

## 구현한 규칙

`GameSimulation.CheckSquadronLaunch`는 상태를 읽기만 하는 공통 검사입니다. `LaunchSquadron`은 같은 검사를 통과한 뒤에만 군수품을 차감하고 출격 상태로 전환합니다. 전투 UI도 이 결과로 임무 버튼을 활성화합니다.

- 배정 ID가 없거나 승무원을 찾을 수 없으면 출격 불가.
- 사망한 조종사는 남아 있는 체력 값과 무관하게 출격 불가.
- 체력이 0 이하인 구조 대기 조종사는 출격 불가. 살아 있고 체력이 양수인 부상자는 기존처럼 출격 가능.
- `onSortie`가 켜져 있거나 같은 조종사를 사용하는 다른 편대가 출격·임무·귀환 중이면 출격 불가. 잘못된 옛 저장 상태에서 플래그만 꺼진 경우도 차단.
- 기존 전투 단계·비행갑판 동력·편대 상태·군수품 조건 유지. 정의되지 않은 임무와 폭격/강습의 존재하지 않는 적 구획도 차단.
- 검사와 거절은 자원·승무원·편대 타이머·로그·RNG를 변경하지 않음.

편대 카드에는 한국어/영어 차단 사유, 조종사 이름, 실제 출격 군수품 비용을 표시합니다. 비용 표시와 검사는 모두 편대 콘텐츠의 비용을 우선하며, 콘텐츠가 없는 기존 편대는 저장된 비용을 사용합니다. 진행 중인 편대의 기존 임무·귀환 표시는 유지합니다.

구조·치료로 살아난 조종사는 다시 출격할 수 있습니다. 반면 기체를 보충하는 `RefitSquadrons`는 사망한 조종사를 부활시키지 않습니다. 조종사 재배정 UI, 비행 중 사망 처리 재설계, 귀환 규칙 변경은 이번 범위에 포함하지 않았습니다. 런 v1·프로필 v2를 유지하므로 마이그레이션은 추가하지 않았습니다.

## 검증 결과

- Unity EditMode **163/163**, PlayMode **13/13** 통과.
- 새 EditMode 27개: 조종사 불가 상태 9종, 정상 임무 5종, 잘못된 임무/표적, 중복 배정과 실제 귀환, 병원선 구조, 기체 보충, 저장·재개, 비용·갑판 검사.
- 새 PlayMode 3개: 양 언어의 4가지 조종사 사유와 임무 버튼 5종, 늦게 도착한 버튼 이벤트의 명령 계층 거절, 구조 후 활성화·공유 조종사 잠금, 비용 일치.
- 전체 C# 컴파일 스모크·프로젝트 정적 검사·감사 하네스 8개 검사 통과.
- macOS 개발 빌드 성공. 1600×900 창 설정으로 한국어 및 영어·고대비 화면에서 사망/구조 대기 사유, 조종사 이름·비용, 비활성 버튼 배치를 확인. Windows 실행·다양한 해상도·사람의 캠페인 완주는 미검증.

### 600회 표준 난이도 회귀

3기함 × `legacy/adaptive` × 100시드(`17000 + i × 7919`), 6공역 캠페인. 기존 보고서 `wing-policies-standard-17000.json`과 비교했습니다.

| 기함 | 기존 정책 완주 | 상황 대응 완주 |
|---|---:|---:|
| 여명의 피난처 | 38/100 | 48/100 |
| 철벽 | 45/100 | 50/100 |
| 서풍 연 | 9/100 | 17/100 |

600개 각각의 승패·도달 지역은 이전과 같으며 시간 제한은 0회입니다. **세부 기록까지 모두 같지는 않습니다.** 기존 정책의 여명 시드 `143704`는 출격 32→29회·편대 군수품 49→46, 서풍 시드 `468383`은 출격 31→30회·군수품 50→49로 바뀌었고 공습·전투 시간 등도 달라졌습니다. 나머지 598개 기록은 동일합니다. 조종사 검증을 이미 수행하던 `adaptive`의 300개 기록은 모두 동일합니다. 이는 선택한 시드에서의 회귀 결과이며 모든 플레이 결과의 불변이나 사람의 목표 완주율을 보장하지 않습니다.

원본 감사 파일은 덮어쓰지 않았습니다. 이번 실행의 시드별 기록과 소스 SHA-256은 `docs/audits/pilot-guard-standard-17000.json`에 보관합니다.

```sh
python3 tools/compare_wing_policies.py --policies legacy adaptive --output docs/audits/pilot-guard-standard-17000.json
python3 tools/test_wing_audit.py
python3 tools/validate_project.py
bash tools/compile_all_csharp.sh
```

## 화면 재현과 다음 작업

개발 빌드에서 `-debug-combat cutter -debug-pilots`로 첫 조종사 사망·둘째 구조 대기인 일시정지 전투를 엽니다. `-debug-english -debug-high-contrast`를 추가하면 영어·고대비 검수가 가능합니다. 이 플래그는 릴리스 빌드에서 작동하지 않습니다. 후속 재현실 구현부터 디버그 저장은 일반 저장과 분리됩니다(`REPRODUCTION_LAB.md`).

이 작업 당시 다음 우선순위는 **서풍 연의 세 번째 편대 표시·조작**이었습니다. 이후 전체 편대 UI와 단축키·회귀 테스트 보강을 완료했습니다(`SQUADRON_UI_COMPLETION.md`). 다음은 수동 시드 재현·운용 검증이며, 마지막으로 밸런스 조정을 진행합니다.
