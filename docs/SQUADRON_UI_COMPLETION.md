# 전체 편대 표시·조작 보강

기준일: 2026-09-05. 서풍 연에 실려 있던 세 번째 정찰 편대가 전투 UI와 숫자키 처리에서 누락되던 문제를 수정했습니다. 시뮬레이션·함선 수치·편대 비용·세이브 스키마는 변경하지 않았습니다.

## 화면과 조작

- 2개 편대는 기존의 두 행 배치를 유지합니다. 3개 이상은 하단의 같은 영역을 나란한 편대 카드로 사용해 함선 내부·무장 패널 공간을 줄이지 않습니다.
- 각 편대의 이름·전력·임무 상태·진행 막대·조종사·실제 군수품 비용과 요격/폭격/호위/정찰/강습 버튼을 모두 표시합니다. 스크롤이나 페이지 전환 없이 현재 기함의 모든 편대를 조작할 수 있습니다.
- 좁은 화면 비율이나 UI 확대 시 편대 패널 너비를 창 안으로 맞춥니다. 일시정지 중 창 크기가 바뀌어도 `LateUpdate`에서 표시 크기만 조정하며 UI 전체 재생성·시뮬레이션 진행·저장을 하지 않습니다.
- 비행갑판 동력 경고와 튜토리얼 힌트가 같은 곳에 겹치지 않도록 동력 경고를 우선합니다.
- 기존 진행 막대는 높이 4px가 내부 여백에 전부 소모되어 채움이 보이지 않았습니다. 6px로 보강하고 실제 채움 높이·50% 진행 너비를 검사합니다.

| 입력 | 임무 |
|---|---|
| `1`, `2` | 기존처럼 해당 슬롯의 폭격 |
| `3` | 서풍의 기본 세 번째 편대인 먼눈 정찰대의 정찰 |
| 추가 슬롯 숫자키 | 장착된 병과에 따른 요격/폭격/호위/정찰/강습. 항구 교체 시 자동 갱신 |
| 임무 버튼 | 각 편대에 표시된 다섯 임무 중 직접 선택 |

`SquadronShortcuts.MissionFor`를 숫자키와 버튼의 키 표시가 함께 사용합니다. 추가 슬롯은 편대 콘텐츠의 병과를 우선하고, 정의를 찾을 수 없는 기존 상태는 저장된 병과로 대체합니다. 입력 처리의 최대 범위는 1–9이며 현재 기함은 2–3개 편대만 탑재합니다. 4개는 UI 확장 검사용 구성이고 신규 기함이나 추가 격납고 콘텐츠를 출시한 것은 아닙니다.

숫자키 폭격은 이제 마우스와 동일하게 선택한 적 구획을 공격합니다. 저장 후 재개할 때도 저장된 선택 구획을 화면에 복원합니다. 출격 가능 여부는 기존 `CheckSquadronLaunch`를 그대로 사용하므로, 조종사 사망/구조 대기/미배정/출격 중·갑판 무동력·비용 부족이면 세 번째 편대도 같은 사유로 차단됩니다. 무료 정찰 편대 `far_eyes`는 군수품 0에서도 출격 가능한 기존 규칙을 유지합니다.

## 검증

- EditMode: 기존 163개 + 단축키 매핑 16개 = **179/179 통과**.
- PlayMode: 기존 13개 + 전체 편대 UI 6개 = **19/19 통과**.
- 모든 기함과 4편대 검사용 구성에서 한국어/영어·고대비 배치, 카드/버튼 경계, 임무 버튼·아이콘 위 마우스 판정 확인.
- 640×480 테스트 화면에서 오른쪽 버튼이 화면 밖으로 나가던 문제를 재현하고 너비 보정 후 통과. 115% UI 확대 중에도 패널을 새로 만들거나 게임 상태를 바꾸지 않고 세 번째 편대 명령이 창 안에 유지되는지 확인.
- 세 번째 편대의 무료 정찰 출격 → 저장/재개 → 임무 → 귀환 → 재출격, 기존 1/2 폭격과 선택 표적, 항구에서 강습 편대로 교체 후 3번 키·표시 갱신 확인.
- 양 언어의 조종사/갑판/군수품 차단 사유, 잘못된 슬롯·음향 설정 화면·비전투 상태에서의 단축키 무동작 확인.
- 새 PlayMode 검사는 별도의 임시 저장소를 사용하고 프로필과 언어 설정을 복원합니다.
- 전체 C# 컴파일 스모크·프로젝트 정적 검사 통과, macOS 개발 빌드 성공. 1600×900 창 설정으로 한국어 3편대 화면과 실제 `3` 키 정찰 출격, 영어·고대비의 사망/구조 대기/준비 상태 및 수정한 진행 막대를 확인했습니다.

게임의 전투 규칙과 감사 입력 코드는 바꾸지 않았으므로 캠페인 자동 플레이 비교를 다시 실행하거나 이전 감사 JSON을 덮어쓰지 않았습니다. 이전 600회 조종사 검증 회귀는 `PILOT_LAUNCH_VALIDATION.md`에 보존되어 있습니다.

## 재현과 남은 범위

개발 빌드에 `-debug-combat cutter -debug-flagship ship_zephyr`를 전달하면 3편대 화면으로 진입합니다. `-debug-english -debug-high-contrast`로 영어·고대비 확인이 가능하고, `-debug-pilots`는 첫 두 조종사를 사망/구조 대기로 만들어 차단 상태도 함께 보여 줍니다. 후속 재현실 작업부터 이 경로도 일반 저장소와 분리됩니다(`REPRODUCTION_LAB.md`).

이번 너비 보정은 편대 패널만 대상으로 합니다. 상단 함선·항구·사건 등 다른 화면의 반응형 배치, 4개를 초과하는 편대 구성, Windows 실제 입력, 전체 해상도별 가독성·60fps·사람의 캠페인 운용 평가는 별도입니다.

후속 작업에서 **시드 지정·전투 스냅샷을 통한 수동 재현 도구**를 완료했습니다(`REPRODUCTION_LAB.md`). 다음은 감사 지점의 스냅샷 내보내기와 기관사 잔류·정찰 유지·요격 예약의 수동 비교이며, 이후 밸런스 변경 여부를 판단합니다.
